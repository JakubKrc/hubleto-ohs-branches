# Ohs Branches

Branches of the clients, job positions with hazard categories, categorisation of work, deficiencies.

Hubleto app of the Ohs set (occupational health service, Slovakia). Namespace: `Hubleto\App\External\WaiBlue\OhsBranches`.
Needs: `wai-blue/hubleto-ohs-core`.

## Install into a Hubleto project

```bash
composer config repositories.wai-blue/hubleto-ohs-branches vcs <repository-url>
composer require wai-blue/hubleto-ohs-branches:dev-main
php hubleto app install "Hubleto\App\External\WaiBlue\OhsBranches"
npm run build
```
